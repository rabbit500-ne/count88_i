オセロ棋譜数カウントシステム ユーザ仕様書

# 概要
本システムは、ブラウザベースの分散計算によりオセロの全棋譜数をカウントするシステムです。ユーザーはブラウザを開くだけで、自動的に計算タスクを取得し、計算を実行して結果を送信します。

# タスクの種類
システムでは2種類のタスクが配布されます：

## BFSタスク
幅優先探索（Breadth-First Search）タスク。指定された局面から一定の深さまで探索し、到達可能な局面のリストと各局面への到達パス数を返します。この結果は、次のフェーズのタスク生成に使用されます。

## DFSタスク
深さ優先探索（Depth-First Search）タスク。指定された局面から終局までの棋譜総数をカウントします。この結果は、最終的な棋譜数の集計に使用されます。

# API仕様
## エンドポイント一覧

| メソッド | パス | 説明 | 認証 |
|---------|------|------|------|
| GET | `/api/v1/task` | タスク取得 | 任意 |
| POST | `/api/v1/result` | 結果送信 | 任意 |
| GET | `/api/v1/progress` | 進捗照会 | 不要 |
| GET | `/api/v1/health` | ヘルスチェック | 不要 |
| GET | `/api/v1/stats` | 統計情報 | 不要 |

## タスク取得API
### リクエスト
```
GET /api/v1/task HTTP/1.1
Host: api.count88.example.com
User-Agent: count88-client/1.0
X-Client-ID: browser-abc123
```

### レスポンス（成功）
```json
{
  "task_id": "1234567890",
  "task_type": "BFS",
  "position": {
    "black": "0x0000000810000000",
    "white": "0x0000001008000000",
    "turn": "black"
  },
  "depth": 7,
  "parent_task_id": null,
  "estimated_time": 5.0,
  "timestamp": "2025-11-18T10:00:00Z"

```

### レスポンス（タスクなし）
```

```

# データ構造
## 局面表現（ビットボード）
APIでは、局面を以下の形式で表現します：

```json
{
  "black": "0x0000000810000000",
  "white": "0x0000001008000000",
  "turn": "black"
}
```

- `black`: 黒石の配置を16進数文字列で表現（64bitビットボード）
- `white`: 白石の配置を16進数文字列で表現（64bitビットボード）
- `turn`: 手番（"black" または "white"）

例: 初期配置
```json
{
  "black": "0x0000000810000000",
  "white": "0x0000001008000000",
  "turn": "black"
}
```

## 多倍長整数
棋譜数は非常に大きな数値（最大約10^58）のため、文字列形式で表現します。JavaScriptでは`BigInt`、Pythonでは組み込み`int`、データベースでは`NUMERIC(80, 0)`（最大80桁）を使用します。

## タスク結果形式
タスク結果は`task_answer`配列形式で送信します。

### DFS結果の形式
```json
{
  "task_answer": [
    {
      "label": "game_count",
      "value": "123456789012345678901234567890"
    }
  ]
}
```

### BFS結果の形式
```json
{
  "task_answer": [
    {
      "label": "child_positions",
      "value": [
        {
          "position": {
            "black": "0x0000000810000000",
            "white": "0x0000001008000000",
            "turn": "white"
          },
          "path_count": 1
        }
      ]
    }
  ]
}
```

# UI仕様
## 画面構成
システムはhtmxを使用した動的なUIを提供します。

## 進捗表示
`GET /ui/progress` エンドポイントで、進捗情報をHTMLフラグメントとして取得できます。htmxの`hx-swap`を使用して部分更新を行います。

## 統計情報表示
`GET /ui/statistics` エンドポイントで、統計情報をHTMLフラグメントとして取得できます。

## タスク一覧表示
`GET /ui/tasks` エンドポイントで、タスク一覧をHTMLフラグメントとして取得できます。
