# プロジェクト概要
オセロ（リバーシ）の全棋譜数を正確にカウントするための分散計算システムを構築する。

# 背景
- オセロの理論的な棋譜数は約 10^58 と推定されている
- 単一マシンでの計算は現実的でないため、ブラウザベースの分散計算を採用
- 学術的価値：ゲーム理論、組み合わせ論への貢献

# 目標
主目標: オセロの全棋譜数の厳密値を算出する

副目標:
- 分散計算基盤の構築
- 計算進捗のリアルタイム可視化
- 中間結果の永続化

# スコープ
対象: 標準8×8オセロの全合法手順
範囲: 初手から終局まで
除外: パスルール、引き分けの扱いは後で定義

# 制約条件
## 性能要件
- レスポンスタイム: タスク取得 < 100ms
- スループット: 1000 req/sec
- 同時接続数: 10,000クライアント

## 可用性
- 稼働率: 99.9%（年間停止時間 < 9時間）
- データ保護: 日次バックアップ

## スケーラビリティ
- 水平スケール: APIサーバの負荷分散
- 垂直スケール: DBのスペック増強

## セキュリティ
- 認証: クライアント認証（APIキーまたはトークン）
- 改ざん防止: 結果のランダム検証（一部タスクを再計算）
- DDoS対策: レート制限

# 成功基準
1. 正確性: 既知の部分結果（例: 10手目までの棋譜数）と一致
2. 完遂: 全タスクの完了
3. 再現性: 同じ計算を複数回実行して同じ結果
4. パフォーマンス: 合理的な期間内（目標: 6ヶ月以内）で完了
